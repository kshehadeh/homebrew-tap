# kshehadeh/homebrew-tap

Homebrew packages published by [kshehadeh](https://github.com/kshehadeh).

```sh
brew install --cask kshehadeh/tap/store
```

| Package | Description |
|---|---|
| [`store`](https://github.com/kshehadeh/store) | Keep files, folders, and text in a 1Password vault and pull them back anywhere |

Casks in `Casks/` are generated by each project's release workflow. Do not
edit them by hand; changes are overwritten by the next release.
